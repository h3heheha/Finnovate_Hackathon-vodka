ONE-TIME SETUP (use the email on YOUR GitHub account, or the
commits won't appear on your profile):

git config --global user.name "Your Name"
git config --global user.email "your-github-email@example.com"

STEPS
-----
WAIT until Member 1 has pushed and you have accepted the collaborator
invite (check your email / github.com/notifications).

1. Clone the repo:

git clone https://github.com/<MEMBER1-USERNAME>/fraudlens.git
cd fraudlens

2. Unzip this file and copy everything inside its "fraudlens" folder
   into your cloned "fraudlens" folder (same structure, merge folders).
3. In the cloned folder, commit in small steps:

git add backend/app/engine/detectors
git commit -m "Add rule-based detectors (phrases, entities, sender)"

git add backend/app/engine/scoring.py backend/app/engine/pipeline.py backend/app/engine/__init__.py
git commit -m "Add risk scoring and analysis pipeline"

git add backend/app/engine/explain.py backend/app/engine/redaction.py
git commit -m "Add explanations and PII redaction"

git add backend/app/engine/ai
git commit -m "Add optional AI provider layer"

git add backend/app/knowledge
git commit -m "Add scam tactics knowledge base, quiz and samples"

git add backend/tests/test_engine.py
git commit -m "Add engine tests"

4. Push:

git pull --rebase origin main
git push

CHECKS
------
- Run "git status" before each commit. You should only see your files.
- NEVER add backend/.env (it holds the real API keys). It is not in
  this package and .gitignore blocks it.
- If "git push" is rejected, run "git pull --rebase origin main" and
  push again. Your folders don't overlap with anyone else's, so there
  will be no conflicts.
