FraudLens V2: set-up guide

Free cloud server on Render + the Chrome extension. About 30 minutes the first time, most of it waiting.

What is in this folder

EXTENSION V2 ├── START HERE.html ← this guide ├── MY_KEYS.txt ← your API keys (never upload this file) ├── 1-server ← goes to GitHub, then Render builds and runs it ├── 2-chrome-extension ← load this folder into Chrome └── 3-backup-and-tests ← Plan B (server on this laptop) and automatic tests

The extension holds no keys. Every key stays on the server, and the extension talks only to your server.

1 Keys: the free APIs 10 min, optional but recommended

FraudLens works without any key (rules, our own AI models, OpenPhish, domain age, the phone check). Keys add more security databases and AI explanations. Open MY_KEYS.txt in Notepad: your Safe Browsing, URLhaus and Telesign keys are already in it.

Get the two new free keys

  1. Groq: console.groq.com/keys → sign in with Google → Create API Key → copy it (it starts with gsk_) → paste after FRAUDLENS_GROQ_API_KEY= in MY_KEYS.txt.
  2. VirusTotal: virustotal.com/gui/join-us → sign up and confirm the email → click your name (top right) → API key → copy → paste after FRAUDLENS_VIRUSTOTAL_KEY=.
Replace the old keys. Your Safe Browsing, URLhaus and Telesign keys were inside the old fraudlens.zip on Google Drive. Make new ones (Google Cloud Console → Credentials, auth.abuse.ch, Telesign portal), delete the old ones, and update MY_KEYS.txt.

2 Put the server on GitHub 5 min

  1. Sign in at github.com (create a free account if you have none).
  2. Click + (top right) → New repository. Name: fraudlens-server. Choose Private. Don't tick "Add a README". Click Create repository.
  3. On the new, empty page click the link uploading an existing file.
  4. In Windows, open EXTENSION V2\1-server, press Ctrl+A to select everything inside it, and drag it onto the GitHub page. Wait until all files are listed (about 94).
  5. Click Commit changes.
Check: the repository's main page must show Dockerfile, render.yaml and the folders app, models… directly, not inside a 1-server folder. Never upload MY_KEYS.txt or the whole EXTENSION V2 folder.

3 Start the free server on Render 10–15 min, mostly waiting

  1. Go to render.com → Sign up with GitHub (no credit card needed).
  2. Click New + → Blueprint. Connect your GitHub account when asked, and give Render access to fraudlens-server.
  3. Choose fraudlens-server. Render reads render.yaml and shows one free web service called fraudlens.
  4. It asks for the keys: for each one, copy the value from MY_KEYS.txt. Leave the ones you don't have empty (if Render insists on a value, type none).
  5. Click Deploy Blueprint (or Apply). Open the fraudlens service and wait until it says Live. The first build downloads the AI model and takes 5–10 minutes.
  6. At the top of the service page, copy its address, e.g. https://fraudlens-abcd.onrender.com. Open it: you should see "The server is running."
If "Blueprint" doesn't work: create the service by hand
  1. New + → Web Service → choose fraudlens-server.
  2. Name fraudlens · Region Frankfurt · Language Docker (detected) · Instance type Free.
  3. Environment Variables: add FRAUDLENS_REQUIRE_INSTALL_TOKEN = true, FRAUDLENS_REPORT_CONFIRMATIONS = 1, plus each key from MY_KEYS.txt (same names).
  4. Advanced → Health Check Path /health → Create Web Service.

4 Install the Chrome extension 2 min

  1. Open chrome://extensions. If the old FraudLens Guard is there, click Remove (both use the same ID).
  2. Switch on Developer mode (top right) → Load unpacked → choose EXTENSION V2\2-chrome-extension.
  3. A Welcome to FraudLens tab opens. Paste your Render address → Connect → click Allow when Chrome asks. After a few seconds (up to a minute if the server was asleep) you see ✓ Connected and a list of services with ✓ / ✗ / –.
  4. Pin the extension: puzzle icon 🧩 → pin 📌 next to FraudLens Guard.
A ✗ next to a service means its key is wrong or used up. Fix it in Render → your service → Environment, then click Save changes (Render restarts the server by itself, about 3 minutes). Then check again: FraudLens panel → Settings & privacy → Check services.

6 Presentation day

  • The free server sleeps after 15 minutes without visitors, and waking it takes about a minute. While Chrome is open with FraudLens, it visits the server every 10 minutes to keep it awake (Settings → "Keep the free server awake", on by default).
  • 30 minutes before: open Chrome, open the FraudLens panel, and check that the header says Connected. Open the practice pages once.
  • If the panel says Waking up…, wait: checks resume by themselves.
  • Keep the Wi-Fi password of the venue (or a phone hotspot) ready.

7 Plan B: no internet or Render down

  1. Try this once at home, with internet (the first run installs packages, 3–5 minutes).
  2. Double-click 3-backup-and-tests\RUN_SERVER_ON_THIS_PC.bat. Wait for Application startup complete. Keep the window open, and don't click inside it.
  3. FraudLens panel → Settings & privacy → server 127.0.0.1:8000 → Connect.
  4. Practice pages: http://127.0.0.1:8000/demo/. The security databases and AI explanations need internet; the warning-sign rules, our own AI models and the phone check work offline.
  5. Back to Render afterwards: paste the Render address again and click Connect.

RUN_SERVER_TESTS.bat runs the 89 automatic server tests (after the Plan B file has run once).

If something goes wrong

Render build fails

Open the service → Logs. "Model download failed" means Hugging Face was busy: click Manual Deploy → Deploy latest commit. "Dockerfile not found" means the files were uploaded inside a folder: re-upload the contents of 1-server (step 2).

"Can't reach the server" / "Couldn't verify"

Open your Render address in a tab. If it loads slowly, the server was asleep: wait a minute, then click Test connection in the panel. Check that the address in Settings is exactly your Render address (https://…onrender.com). "Couldn't verify" never means safe.

Connect says "Chrome wasn't allowed to talk to that server"

Click Connect again and choose Allow in Chrome's pop-up.

No banners on Gmail / WhatsApp

Tick the site in Settings & privacy, click Allow, then reload the tab. Only suspicious messages (links, numbers, money or pressure words) are checked.

A service shows ✗

The text next to it says why (key rejected, quota used). Fix the key in Render → Environment → Save changes, wait for "Live", then click Check services again. Telesign ✗ usually means the trial credits are used up: that's fine, the offline phone check still works.

"Load unpacked" error about the extension ID

Remove the old FraudLens Guard first (step 4.1), then load 2-chrome-extension again.

Plan B window closes or shows an error

Install Python 3.12 from python.org (tick "Add python.exe to PATH"), delete 3-backup-and-tests\.venv, and run the file again. If it still fails, copy the error text and send it to Claude.
