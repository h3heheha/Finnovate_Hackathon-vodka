Privacy
  • Messages are checked on this computer first. Only suspicious ones (a link, a number, money or pressure words) go to your FraudLens server.
  • The server removes card, account, phone, OTP, NIC and email details before any AI sees the text.
  • Website addresses are checked on this computer. Only addresses that look like a scam (a fake bank or brand name, free hosting, a raw IP address, "login/verify" words) are sent to the security databases, without the part after "?".
  • Pause-Before-Pay only notices that you clicked into a field on a page FraudLens flagged. It never reads what you type. Continuing is only possible from this panel, which a web page can't fake.
  • No API keys are stored in this extension. Results are kept in memory and cleared when Chrome closes.
