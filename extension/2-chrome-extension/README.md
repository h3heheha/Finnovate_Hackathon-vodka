# FraudLens Guard (Chrome extension)

Install: `chrome://extensions` → switch on **Developer mode** → **Load unpacked** → choose this folder.
A welcome page opens. Paste your FraudLens server address and click **Connect**.

- **Scam X-Ray** for messages in Gmail, Outlook and WhatsApp Web (switch these on in Settings), and any text you paste or right-click.
- **Link check** before a link in a flagged message opens.
- **Look-alike site warnings** (mcb-secure-verify.com, rncb.mu, netflix-billing…), even on dead scam sites.
- **Pause-Before-Pay**: on a flagged page, the first click into a field pauses the page with a countdown. You can continue only from the side panel.
- The toolbar badge and the side panel always show the true verdict. A web page can't reach them.

The extension ID is pinned (`bnoincbnfccidpkdnfelgejnldhicimk`) so the server accepts only this extension.
No API keys are stored here.
